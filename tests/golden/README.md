# Golden set

Курований набір регресійних евалів якості (docs/06 §2, docs/09 §3) — **реліз-гейт**
для змін у extraction/normalization/rag.

- `test_extraction_golden.py` — детермінований прогін реальних екстракторів (Tier 1/2/3)
  і нормалізації по фікстурах з еталонними канонічними фактами. Без мережі, БД і LLM
  (docs/09 §2). Падіння точності нижче базового рівня (`BASELINE_ACCURACY`) валить білд.
- Кожен новий кейс: фікстура сирої сторінки + очікувані `attribute_key → canonical_value`.
- Репортована користувачем помилка додається сюди як кейс перед фіксом (docs/06 §7).

Запуск: `pytest -m golden` або `python tools/dev.py golden`. Виконується в CI окремим кроком.
